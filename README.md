
# Digital Logic Design Virtual Lab

An interactive web-based laboratory designed to help
B.Tech Electronics and Communication Engineering students
learn and experiment with Digital Logic Design.

## Features

- Interactive simulation of seven basic logic gates
- Dynamic truth tables
- Boolean algebra laws
- Interactive 2-variable Karnaugh map
- Half Adder and Full Adder simulation
- 2:1 Multiplexer simulation
- Responsive dark-themed interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Explore the different laboratory modules.

## Purpose

This project was developed as a learning project
to understand digital logic, Boolean expressions,
truth tables and combinational circuits.
