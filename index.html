Learn Digital Logic Design

Important concepts for DLD laboratory experiments, assignments and examinations.

1. Basic Logic Gates

  • AND: output is 1 when both inputs are 1.
  • OR: output is 1 when at least one input is 1.
  • NOT: output is the opposite of the input.
  • NAND: opposite of the AND output.
  • NOR: opposite of the OR output.
  • XOR: output is 1 when inputs are different.
  • XNOR: output is 1 when inputs are equal.

2. Universal Gates

NAND and NOR are called universal gates because any Boolean function can be implemented using only NAND gates or only NOR gates.

NOT using NAND: Y = (A · A)' = A'

NOT using NOR: Y = (A + A)' = A'

AND using NAND: Y = ((A · B)')'

3. Half Adder

A half adder adds two one-bit binary numbers.

Sum = A XOR B

Carry = A AND B

4. Full Adder

A full adder adds three bits: A, B and carry input.

Sum = A XOR B XOR Cin

Cout = AB + ACin + BCin

5. Multiplexer

A multiplexer selects one of its input signals and sends it to the output according to the select line.

Y = S' · I0 + S · I1

6. Boolean Algebra

Boolean algebra uses binary values 0 and 1 to describe and simplify digital logic circuits.

K-maps help simplify Boolean expressions by grouping adjacent cells containing 1.
